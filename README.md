# Sobre Etnias — site multipáginas

## Como executar
1. Extraia o ZIP.
2. Abra esta pasta no Visual Studio Code.
3. Instale a extensão **Live Server**.
4. Clique com o botão direito em `index.html` e escolha **Open with Live Server**.

## Páginas
- `index.html`: início
- `protagonismo.html`: Protagonismo e História
- `cultura.html`: Cultura e Conhecimento
- `glossario.html`: Aprendizado · Glossário
- `quiz.html`: Quiz

Cada item do menu abre uma página HTML independente. Todas compartilham `style.css` e `script.js` para manter o mesmo visual e os recursos interativos.

## Recursos
- Cabeçalho fixo com menu principal e rodapé com navegação em todas as páginas.
- Entrada editorial em duas etapas (fólio + tela de entrar), com opção de pular.
- Filtros de personalidades, abas de cultura, busca no glossário e quiz.
- Animações de hover, revelação ao rolar e botão "voltar ao topo".
- Atalho `/` para a busca do glossário e `Pular para o conteúdo` por teclado.
- Respeito a `prefers-reduced-motion` e navegação por teclado.

Sem frameworks, sem build e sem dependências externas: basta abrir os arquivos.
